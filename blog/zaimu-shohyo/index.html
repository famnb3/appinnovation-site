簿記3級｜財務諸表（貸借対照表・損益計算書）の作り方【第3問】

公開日：2026年8月17日

「決算整理仕訳までは書けたのに、財務諸表に書き写す段階で手が止まる」「貸借対照表の合計がどうしても一致しない」——簿記3級の第3問で財務諸表が出題されたときによく聞く悩みです。

財務諸表の問題は、決算整理後の各勘定の残高を表の形に並べ替える作業です。つまずく箇所は「表示科目の読み替え」「評価勘定の純額表示」「当期純利益の行き先」の3つにほぼ集約されます。この記事では、その3つを確認したうえで、数値付きの例題で1つの財務諸表を最後まで作ります。

財務諸表問題でつまずく3つのポイント

ポイント1：勘定科目を表示科目に読み替える

帳簿で使う勘定科目と、財務諸表に載せる表示科目は名前が違うものがあります。ここを読み替えずに書くと、金額が正しくても失点につながります。代表的なものは次のとおりです。

決算整理後の勘定科目財務諸表の表示科目表示する場所
繰越商品商品貸借対照表・資産
仕入売上原価損益計算書・費用
売上売上高損益計算書・収益
前払家賃・前払保険料前払費用貸借対照表・資産
未払給料・未払利息未払費用貸借対照表・負債
前受家賃・前受手数料前受収益貸借対照表・負債
未収手数料・未収利息未収収益貸借対照表・資産

前払費用・未払費用などの経過勘定の考え方は、経過勘定（前払・前受・未払・未収）の記事で詳しく解説しています。

ポイント2：貸倒引当金・減価償却累計額は「純額」で示す

貸倒引当金と減価償却累計額は、資産のマイナスを表す評価勘定です。貸方残高ですが負債ではありません。貸借対照表では、対象となる資産の下に控除する形で並べ、差し引いた金額（純額）を右端に書きます。

  • 売掛金 400,000円、貸倒引当金 8,000円 → 純額 392,000円
  • 備品 600,000円、減価償却累計額 240,000円 → 純額 360,000円

この2つを負債側に足してしまうと、貸借が両側とも膨らんで合計が一致しません。合計が合わないときに最初に見直したい箇所です。

ポイント3：当期純利益は繰越利益剰余金に含める

損益計算書で求めた当期純利益は、貸借対照表では独立した行にはなりません。試算表の繰越利益剰余金（期首残高）に当期純利益を足した金額を、純資産の繰越利益剰余金として表示します。精算表では利益を独立した行に書くため、混同しやすい違いです。精算表側の書き方は精算表の解き方の記事にまとめています。

例題：決算整理後の残高から財務諸表を作る

決算整理後の残高が次のとおりだったとします（会計期間は1年）。

借方の科目金額貸方の科目金額
現金145,000円買掛金260,000円
売掛金400,000円未払給料12,000円
繰越商品120,000円貸倒引当金8,000円
前払保険料30,000円備品減価償却累計額240,000円
備品600,000円資本金500,000円
仕入900,000円繰越利益剰余金100,000円
給料180,000円売上1,500,000円
支払家賃120,000円
減価償却費120,000円
貸倒引当金繰入5,000円

このうち、減価償却と貸倒引当金の決算整理仕訳は次のように行われています。

  • 減価償却費：600,000円 ÷ 5年 = 120,000円
    （借）減価償却費 120,000 ／（貸）備品減価償却累計額 120,000
  • 貸倒引当金：400,000円 × 2% = 8,000円、期首残高3,000円との差額を補充
    （借）貸倒引当金繰入 5,000 ／（貸）貸倒引当金 5,000

計算の考え方は減価償却の記事、貸倒引当金の記事で個別に解説しています。

損益計算書をつくる

収益と費用を集めて差額を求めます。仕入は売上原価、売上は売上高に読み替えます。

費用金額収益金額
売上原価900,000円売上高1,500,000円
給料180,000円
支払家賃120,000円
減価償却費120,000円
貸倒引当金繰入5,000円
当期純利益175,000円
合計1,500,000円合計1,500,000円

費用の合計は900,000円 + 180,000円 + 120,000円 + 120,000円 + 5,000円 = 1,325,000円です。収益1,500,000円との差額1,500,000円 − 1,325,000円 = 175,000円が当期純利益になります。

貸借対照表をつくる

評価勘定を控除した純額で資産を並べ、繰越利益剰余金には当期純利益を加算します。

資産金額負債・純資産金額
現金145,000円買掛金260,000円
売掛金 400,000円
貸倒引当金 △8,000円		392,000円未払費用12,000円
商品120,000円資本金500,000円
前払費用30,000円繰越利益剰余金275,000円
備品 600,000円
減価償却累計額 △240,000円		360,000円
合計1,047,000円合計1,047,000円

繰越利益剰余金の計算：試算表の100,000円 ＋ 当期純利益175,000円 = 275,000円。ここに当期純利益を足し忘れると、貸方が175,000円だけ不足します。合計が「利益の分だけ合わない」ときは、まずこの行を確認してください。

資産合計145,000円 + 392,000円 + 120,000円 + 30,000円 + 360,000円 = 1,047,000円、負債・純資産合計260,000円 + 12,000円 + 500,000円 + 275,000円 = 1,047,000円で一致しました。

解く順番のおすすめ

  1. 決算整理事項を1つずつ仕訳にする
  2. 損益計算書の科目（収益・費用）を先に埋めて当期純利益を確定させる
  3. 貸借対照表の資産・負債を、表示科目に読み替えながら埋める
  4. 繰越利益剰余金に当期純利益を加算し、両側の合計を検算する

当期純利益を先に確定させると、貸借対照表の純資産をすぐ埋められます。第3問（配点35点）は空欄ごとに部分点が積み上がるので、1つの整理事項がわからなくても、他の欄を埋めるだけで得点につながります。

まとめ

  • 繰越商品は商品、仕入は売上原価、売上は売上高へ表示科目を読み替える
  • 貸倒引当金・減価償却累計額は資産から控除し、純額を貸借対照表に載せる
  • 当期純利益は独立表示せず、繰越利益剰余金に加算する

手順が固まったら、あとは本試験形式の問題で数をこなすのが定着の近道です。一緒に頑張りましょう。
